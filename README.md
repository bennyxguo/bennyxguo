# G'day, mate! 👋

I'm Benny, a software engineer based in Sydney, Australia, with over 10 years of experience building software.

My background covers full-stack development, enterprise systems, software architecture, and technical leadership. I've worked on everything from web and mobile applications to ERP, CRM, and financial systems, and previously led a team of 20+ engineers.

These days, I'm spending more time on **AI engineering**, particularly LLM orchestration, memory systems, RAG, and building reusable AI infrastructure.

I enjoy understanding how things work, designing practical solutions, and turning ideas into working products.

## 🤖 AI & Current Projects

### 🧠 knowmiii — AI Companion & Core

An AI companion project focused on conversational intelligence, long-term memory, and personalised interactions.

I'm building a reusable AI Core that can be shared across different applications, with a clear separation between AI processing and application-specific data storage.

- LLM orchestration and provider abstraction
- Long-term memory processing and reflection
- Memory retrieval, ranking, and context assembly
- Streaming responses and STT/TTS integration
- Reusable architecture for multiple AI applications

**Tech:** TypeScript, Node.js, LLM APIs, AI Memory, STT/TTS

### 🏨 staymiii — AI Hotel Concierge

An AI-powered hotel concierge platform designed to help guests access hotel information and services through natural conversations.

Currently building the platform with a focus on:

- RAG and hotel knowledge retrieval
- Vector search with PostgreSQL and pgvector
- Multi-turn conversations and guest preferences
- Multi-tenant SaaS architecture
- Guest H5 application and hotel administration portal
- LLM and speech-to-text integrations

**Tech:** React, Taro, NestJS, Prisma, PostgreSQL, pgvector, LLM APIs

### 🏢 CGT Hub — Enterprise Management Platform

An integrated management platform built for an Australian training organisation.

- CRM and Student Management System (SMS)
- Course, class, trainer, and timetable management
- Enrolments, orders, payments, and refunds
- Reporting, document generation, and automation
- Role-based access control and API integrations

**Tech:** React, TypeScript, NestJS, Prisma, PostgreSQL, AWS, Docker

### 📱 Other Projects

- **Humanetrics** — A psychology-based application, covering frontend/backend development and application design.
- **eTag** — An electronic luggage tag platform with web applications, backend services, and a WeChat Mini Program.
